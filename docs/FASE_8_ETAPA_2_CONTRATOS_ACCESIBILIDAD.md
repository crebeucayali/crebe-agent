# Fase 8 — Etapa 2: Contratos y criterios de accesibilidad

## Estado

`ETAPA_2_COMPLETADA_CONTRATOS_ACCESIBILIDAD`

## Objetivo

Definir criterios verificables para las 14 superficies de accesibilidad inventariadas en la Etapa 1, sin auditar todavía cumplimiento, sin asignar severidades y sin modificar los repositorios EVA.

## Referencia técnica

La referencia de evaluación será WCAG 2.2 con objetivo de nivel AA. Esta selección no constituye una declaración de conformidad de EVA; únicamente fija el marco contra el cual se construirá la línea base de la Etapa 3.

## Alcance

Se mantienen exactamente los 8 repositorios EVA y el universo base ya validado de 65 páginas HTML y 1,297 elementos funcionales.

Se definieron 28 contratos, dos para cada una de las 14 superficies inventariadas:

1. Imágenes y texto alternativo.
2. Botones, enlaces y nombres accesibles.
3. Formularios, labels, errores y ayuda.
4. Encabezados y jerarquía semántica.
5. Idioma y títulos de documento.
6. Landmarks y regiones.
7. Navegación por teclado.
8. Foco visible y orden de foco.
9. Modales, diálogos y contenido dinámico.
10. ARIA, roles, estados y propiedades.
11. Tablas y relaciones semánticas.
12. Contraste, alto contraste y color.
13. Zoom, reflujo, tamaño de texto y móvil.
14. Multimedia y componentes administrativos.

## Guardrails

- No se modifican los 8 repositorios EVA.
- No se corrige HTML, CSS o JavaScript.
- No se declara conformidad WCAG.
- No se declaran fallos sin evidencia.
- No se asignan severidades en esta etapa.
- No se inicia la Etapa 3 automáticamente.

## Resultado

- Superficies cubiertas: 14.
- Contratos definidos: 28.
- Hallazgos confirmados: 0.
- Severidades asignadas: 0.
- Correcciones aplicadas: 0.
- Repositorios EVA modificados: 0.

La siguiente etapa, cuando sea autorizada, será la **Etapa 3 — Línea base de accesibilidad**, donde estos contratos se aplicarán como criterios de verificación.
